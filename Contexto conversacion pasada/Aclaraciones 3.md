Qué hace la pantalla (3 pestañas dentro de "Active Product List"):

Product Setup — Hay una "Master Product List" (catálogo completo de productos M-I SWACO) y una "Active Product List" (los productos que realmente se van a usar en este pozo, seleccionados desde el maestro con el botón "Add Product"). Cada producto activo tiene datos propios del proyecto: Abreviación, Unit Size, Unit, Packing, Price, S.G., Calc Conc?, M-I Prod?, Prod Group, Daily Cost Code (clave para asignación de costos), Calc WMgt Conc?, WMgt Cost Category, CF Cost Category. Hay un concepto de "Approved Items" (código+nombre+unidad+empaque bloqueados en amarillo porque coinciden exactamente con el maestro) vs. ítems no aprobados/editados a mano. Desde aquí también se accede a listas activas de Waste Treatment and Disposal y Completion Fluids (probablemente subconjuntos del mismo mecanismo, para esos otros módulos que aún no construimos).
Equipment Rental Setup — Mismo patrón maestro/activo pero para equipos: Serial No., Equipment Code, Description, Equip. Detail (nombre oficial M-I SWACO, no se debe modificar), Rental Price, Stand-By Price.
Shaker Screen Setup — Mismo patrón para mallas de zaranda: Code, Description, Mesh Size, Price, Discount %.

Las tres pestañas comparten botones: Add/Edit/Remove, Copy, Import/Export Active List, Recalc Cum Cost, Edit Short List (etiqueta corta para reportes), Start Quantity.

Benchmark Setup — Es un proceso de 2 pasos, por pozo: (1) "Benchmark Definitions": eliges de una lista larga de parámetros (agrupados por categoría, ej. "Mud Properties", separados por tipo de fluido WBM/OBM) los que quieres monitorear, y los agregas a una lista activa. (2) "Target Entry": una grilla donde para cada parámetro elegido ingresas el valor objetivo (o rango min/max) por sección — columnas "Whole Well" + "Interval 1, 2, 3...". Esas columnas de intervalo coinciden exactamente con los intervalos de revestimiento que ya capturamos en "Well Casing Intervals (Cost)", así que esa parte encaja bien con lo que ya existe. Lo que sí es nuevo: necesito un catálogo maestro de "parámetros de benchmark" (Mud Weight, PV, YP, API Fluid Loss, etc., separados WBM/OBM) para poder ofrecer la lista de selección — ONE-TRAX trae esto precargado.

Equipment Properties Setup — Depende de que ya hayas agregado equipos en "Active Products/Equipment/Screens" (si no, muestra ese mensaje de error que se ve en tu captura). Agrupa el equipo activo por "Tipo de Equipo" (Centrífuga, Mud Cleaner, Shale Shaker, Vacuum System, Cuttings Container, Otros) y por cada tipo muestra una lista de propiedades predefinidas con checkbox (ej. para Centrífuga: Flow Rate, WT In, WT Out, Bowl Speed, G-Force...) más un espacio para propiedades extra de texto libre. La Centrífuga además tiene una config especial de unidades flexibles (Flow Rate / Mass).

Benchmark Setup — pantalla de 2 pestañas por pozo: "Definición de Parámetros" (lista buscable/filtrable por grupo, con checkbox, del catálogo maestro de parámetros) y "Entrada de Objetivos" (grilla con columnas Whole Well + cada Intervalo de Revestimiento ya cargado, filas por parámetro con sub-filas Mínimo/Máximo cuando aplica).

Equipment Properties Setup — agrupa automáticamente el equipo activo del pozo por Tipo de Equipo (usando el nuevo campo que agregamos a Equipo), muestra checkboxes de propiedades estándar por tipo más un espacio para propiedades extra de texto libre, y la configuración especial de unidades flexibles cuando hay una Centrífuga activa. Si el pozo todavía no tiene equipo activo, muestra el mismo aviso que ONE-TRAX pidiendo ir primero a "Productos/Equipos/Mallas Activos".

Catálogos Maestros ahora tiene 4 pestañas (agregué 2): "Propiedades de Equipo" y "Parámetros de Benchmark", totalmente editables por los ingenieros — como pediste, en vez de listas fijas. También agregué el campo "Tipo de Equipo" al formulario de Equipos existente.

Ambas pantallas quedaron habilitadas en el menú del pozo (ya no dicen "Próximamente").
