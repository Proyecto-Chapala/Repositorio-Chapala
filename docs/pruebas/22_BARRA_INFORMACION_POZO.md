# 22 — Barra de navegación de Información del Pozo (18-oct-2026)

## Cómo funciona

Al entrar a cualquiera de las 8 pantallas de *Información del Pozo* (Información General, Configuración General, Intervalos, Pérdidas, Productos / Equipos, Benchmark, Tanques, Propiedades de Equipo) aparece bajo el título una barra con:

- **🏠 Pantalla principal**: vuelve a la pantalla principal del pozo.
- Un botón por cada pantalla; la actual queda resaltada en naranja.

La barra se queda fija arriba al bajar en la página. Si no caben todos los botones, se desplaza de lado.

## Pasos para verificar

- [ ] Abrir un pozo y entrar a *Información General del Pozo*: aparece la barra con "Información General" resaltado.
- [ ] Pulsar "Tanques" en la barra: abre Información de Tanques y ahora "Tanques" queda resaltado.
- [ ] Recorrer las 8 pantallas desde la barra: todas abren y resaltan la correcta.
- [ ] Pulsar "🏠 Pantalla principal": vuelve a la pantalla principal del pozo.
- [ ] En una pantalla larga (Productos / Equipos), bajar: la barra sigue visible arriba.
- [ ] Achicar la ventana: la barra se desplaza de lado sin romper la página.
- [ ] Con el teclado (Tab) se recorren los botones y se ve el borde de foco.
