## Siglas y términos técnicos

| Término | Significado |
|---|---|
| **AOS** | All Oil Services, C.A. |
| **API RP 13B / 13C / 13D** | Prácticas recomendadas del API: pruebas de lodo / sistemas de control de sólidos / reología e hidráulica |
| **BHT** | Temperatura de fondo del hoyo |
| **BOP** | Preventor de reventones |
| **DF / CF** | Drilling Fluids (fluidos de perforación) / Completion Fluids (fluidos de completación) |
| **DLS** | Dogleg severity: severidad de pata de perro (°/100 ft) |
| **DWM** | Drilling Waste Management (manejo de desechos) |
| **ECD** | Densidad equivalente de circulación (lb/gal) |
| **HGS / LGS** | Sólidos de alta / baja gravedad específica |
| **HHP / HSI** | Potencia hidráulica en la mecha / potencia por pulgada cuadrada de mecha |
| **HPHT (HTHP)** | Filtrado a alta presión y alta temperatura |
| **IADC** | International Association of Drilling Contractors (hoja de tiempos, código de mecha) |
| **IFE** | Ingeniero de fluidos y equipos |
| **MBT** | Prueba de azul de metileno (capacidad de intercambio catiónico) |
| **MD / TVD** | Profundidad medida / profundidad vertical verdadera |
| **Mesh** | Número de aberturas por pulgada lineal de una malla |
| **MOC** | Mud on cuttings: lodo retenido en los recortes |
| **MWD** | Measurement while drilling (herramienta de medición en la sarta) |
| **OBM / SBM / WBM** | Lodo base aceite / sintético / agua |
| **PV / YP** | Viscosidad plástica (cP) / punto cedente (lb/100 ft²) |
| **ROP** | Tasa de penetración (ft/h) |
| **SPM** | Emboladas por minuto |
| **Spud** | Inicio de la perforación del pozo |
| **SUS** | Pruebas de sólidos (sin información en el manual) |
| **TD** | Profundidad total |
| **TFA** | Área total de flujo de las boquillas (in²) |
| **Tool joint** | Junta de la tubería de perforación |
| **Washout** | Ensanchamiento del hoyo respecto al diámetro de la mecha |
| **τy (tau y)** | Punto cedente verdadero (modelo Herschel-Bulkley) |
